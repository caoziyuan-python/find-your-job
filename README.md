# 秋招工作台（Job Hunt Workbench）

一个为自己量身打造的秋招全流程记录平台。因为市面上的打卡工具要么太简单（只能记个公司名），要么太复杂（套了个 CRM 的壳），所以干脆自己动手：从投递、笔试、面试到 offer，所有信息一处管理；每轮面试的录音转写和 AI 复盘单独存放、随时回看。

> 本项目为个人独立 0-1 作品：需求定义、信息架构、页面设计、前后端开发全部独立完成。
>
> 📌 **面试官/参观的同学请先看这里**：[产品设计与迭代记录](./产品设计与迭代记录.md) —— 每个功能为什么存在、13 次真实迭代的完整来龙去脉，比代码更能说明问题。

## 功能一览

**📋 进度管理（总览页）**
- 公司卡片式管理：岗位、城市、当前阶段、状态一目了然
- 支持「主动投递 / 被捞」两种来源标记，以及「无笔试流程」的个性化设置
- 顶部统计区：在投 / offer / 已挂数量、各面试轮次占比

**📅 时间管理（时间线视图）**
- 按公司展开完整流程时间线：投递 → 笔试 → 一面 → 二面 → HR 面
- 每个节点可记录时间、时长、面试官、自评、备注
- 「每日」页面：每天新增动态汇总 + 今日待办（笔试/面试提醒）

**🎙️ 面试转写存储区**
- 每一轮面试的录音转文字稿单独归档，按面试官/候选人分角色展示
- 每轮可附 AI 生成的复盘总结，面试前快速回看
- 转写内容支持交互式展开查看

**📊 数据与分享**
- 阶段漏斗、轮次分布等统计图表
- 一键生成分享版长图（小红书排版），配色按阶段区分：笔试/一面/二面等
- 支持完整数据导出，随时备份

## 技术栈

React 19 · TypeScript · Vite · Tailwind CSS · shadcn/ui · Recharts · localStorage 持久化

数据全部存储在浏览器本地，无需登录、无后端、隐私零外传。

## 快速开始

```bash
npm install
npm run dev
```

打开终端提示的本地地址即可使用。
